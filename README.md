# Timetable Management System

A web-based application to automate academic timetable generation for institutions.

## Features

- Role-based dashboards (Admin, Faculty, Student)
- Conflict-free timetable generation
- Real-time updates using Google Sheets API
- Responsive UI design

## Tech Stack

- Backend: Flask (Python)
- Frontend: HTML, CSS, JavaScript
- Database: MongoDB
- UI Design: Figma
- API: Google Sheets API

## Functionality

- Generate and manage timetables
- Assign faculty, rooms, and time slots
- Prevent scheduling conflicts
- Export final timetable to Google Sheets

## How to Run

```bash
pip install -r requirements.txt
python app.py
